Réseau

Le réseau de test IEEE à 14 nœuds. Le courant n'y prend pas le chemin qu'on choisit : il se répartit entre toutes les lignes selon les lois de Kirchhoff. Coupez une ligne : son flux se reporte sur les autres.

L'écart compare le flux à celui du réseau intact, à la même consommation.

Comment lire. Le calcul est le modèle DC : sans pertes, les tensions à 1, seules comptent les réactances des lignes. La centrale du nœud 2 produit ce que dit le fichier (29,5 MW) ; celle du nœud 1, la référence, fournit tout le reste. Il n'y a pas encore de répartition : au-delà de sa Pmax, la page le signale. Une partie du réseau coupée du reste devient un îlot ; sans centrale, sa consommation est perdue. Les limites des lignes sont celles de PGLib. Source : .
